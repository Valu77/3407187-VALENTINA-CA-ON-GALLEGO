Proyecto Semanal — Semana 05: Clasificador
Descripción

En este proyecto se realizó un sistema de clasificación aplicado al dominio agronómico.
Se trabajó con un servicio de análisis de suelo, donde se clasificó según su valor, estado y tipo.

Lógica implementada

Se definieron los datos del servicio como nombre, estado, valor, tipo e información adicional.

Se utilizó if/else para clasificar el servicio en niveles (alta, media, baja).

Se utilizó el operador ternario para determinar si el servicio está activo o inactivo.

Se utilizó switch para clasificar el tipo de servicio.

Se aplicó ?? para asignar valores por defecto cuando no hay datos.

Se utilizó ?. para acceder de forma segura a propiedades del objeto.

Se mostró toda la información en consola usando template literals.

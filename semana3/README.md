# 🌱 Sistema de Gestión - Asesoría Agronómica

## Descripción

Este proyecto implementa un sistema de gestión para una página web de asesoría agronómica utilizando clases avanzadas de JavaScript ES2023.

## Funcionalidades

- Registro de servicios agronómicos
- Registro de clientes
- Contratación de servicios
- Cancelación de servicios
- Validaciones con campos privados
- Métodos estáticos
- Encapsulamiento de datos

## Estructura

- Service → Representa los servicios ofrecidos
- Client → Representa los clientes registrados
- AgronomySystem → Sistema principal de gestión

## Conceptos aplicados

- Clases ES2023
- Campos privados (#)
- Getters y Setters
- Métodos estáticos
- Validación de datos
- Encapsulamiento
